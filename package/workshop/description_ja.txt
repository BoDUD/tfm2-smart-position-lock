[h1]スマートポジションロック Smart Position Lock[/h1]

[b]ひとことで：[/b]ピックでは両チームとも、残りの空きポジションに収まるチャンピオンしか選びません。AIチームのピックが終わると、各チャンピオンは担当できるポジションに配置されます。[b]入れるだけで動作し、設定は不要です。[/b]

[h2]解決すること[/h2]
[list]
[*]AIがトップ専用のチャンピオンを2体選んだり、ガレンをサポートに、サポートをジャングルに配置したりする。
[*]自分のピックで、うっかり空きポジションに収まらないチャンピオンを選んでしまう。
[*]Modチャンピオン（League of Legends Heroes など）はポジションの統計がなく、ピックカードはすべて「トップ+ジャングル」と表示され、AIがでたらめに選び・配置する。
[/list]

[h2]何をするか[/h2]
[list]
[*][b]AIのピック：[/b]AIは毎回、選択済みのチャンピオンと合わせて「1人1ポジション」に収まるチャンピオンだけを選びます。どのポジションから選んでも構いません。
[*][b]AIのレーン配置（ゲーム 0.6.4 以降）：[/b]AIチームが5体を選び終えると、このModが配置します。各チャンピオンを担当できるポジションへ、複数可能ならメインポジションを優先し、同じくらい良い配置が複数あるときは、そのチャンピオンの熟練度が最も高い選手に任せます。熟練度は同等の配置の中から選ぶだけで、担当できないポジションには絶対に置きません。ゲーム 0.6.3 以前はピックの制限のみで、配置はゲームのままです。
[*][b]あなた自身のピック：[/b]空きポジションに収まらないチャンピオンのカードには鍵がかかり、クリックできません。自分のチームのレーンは入れ替えフェーズで自由に決められます。
[*][b]バンは制限しません。[/b]
[*][b]ピックが止まることはありません：[/b]合うチャンピオンが一体もいないときは、ロックは自動的にすべて解除されます。あなたが青か赤か分からないときは、あなた側は何もロックしません。
[/list]

[h2]チャンピオンが担当できるポジション（上から順に、最初に見つかったもの）[/h2]
[olist]
[*][b]あなたの手動指定[/b]（F7 パネルまたは settings.ini、下記参照）——すべてに優先します。
[*][b]League of Legends Heroes のチャンピオン：[/b]全106体のLoL公式メインポジションを内蔵。最初のものが、選べるときに優先するポジションです。コピー不要。
[*][b]その他すべてのチャンピオン（公式チャンピオン、ほかのModのチャンピオン）：[/b]
[list]
[*]ピックカードにゲームが表示する2つのメインポジション（ゲームの統計で「最もよく使われた2つのポジション」。Mod作者が設定したものではありません）；
[*]さらに、このセーブで十分な試合数担当したポジション（既定：8試合以上、かつそのポジションが15%以上。大会の試合もソロランクも含む）。
[/list]
メインポジションは初めてバン/ピック画面を開いたときに覚え、Modフォルダの positions.json に保存されます。AI同士の試合でも使われます。
[/olist]

[h2]ほかのModのチャンピオンをロックするには（重要）[/h2]
ほかのModのチャンピオンも同じようにロック・配置されます。[b]追加のインストールは不要[/b]です。注意点は一つだけ：
[list]
[*]ゲームの統計がまだない新しいチャンピオンは、ピックカードに一律[b]「トップ+ジャングル」[/b]と表示されます。このModはそれをトップとジャングルしかできないと判断します——たとえばサポートのModチャンピオンがトップかジャングルにしか置けなくなります。
[*]解決方法は3つ、どれか一つで大丈夫です：
[olist]
[*][b]F7 パネル（おすすめ・最も簡単）：[/b]一度バン/ピック画面を開いてチャンピオンをリストに出す → どの画面でも F7 → ページをめくってそのチャンピオンを探す → 担当できないポジションを灰色に、できるポジションを緑にクリック。即時反映・自動保存され、以後ずっとその設定になります。
[*][b]settings.ini：[/b]Modフォルダの settings.ini の [positions] セクションに「チャンピオンid=ポジション1,ポジション2」を1行追加。例：[i]my_lux=Mid,Support[/i]。最初がメインポジションです。書き方：Top（トップ）、Jungle（ジャングル）、Mid（ミッド）、Bottom（ボット）、Support（サポート）。保存後数秒で反映、再起動不要。
idが分からない場合：F7 パネルでそのチャンピオンのポジションを一度クリックすると、settings.ini にその行が現れます（idは「=」の前）。あとは自由に編集してください。
[*][b]自動で覚えさせる：[/b]「セーブの試合を参照」をオンのままにすると、そのチャンピオンがセーブで8試合をこなした後、実際に担当したポジションが自動で加わります。
[/olist]
[*]あるチームの5体すべてにポジション情報がないときは、このModは関与せず、配置はゲームに任せます。
[/list]

[h2]ゲーム内設定パネル（F7）[/h2]
どの画面でも [b]F7[/b] で開き、もう一度 F7、Esc または右上の ✕ で閉じます。クリックするたびに即時反映され、settings.ini に自動で書き込まれます（ファイル内のほかの内容やコメントは保持）。パネルの文字はゲームの言語に従います（简体中文、繁體中文、English、日本語、한국어。その他の言語は英語）。

[b]上の4つのスイッチ：緑 = オン、灰色 = オフ[/b]（間違えて押したらもう一度押せば戻ります。基本はすべて緑のままがおすすめ）：
[table]
[tr][th]スイッチ[/th][th]機能[/th][th]オフにすると[/th][/tr]
[tr][td]全体スイッチ[/td][td]Mod全体のオン/オフ[/td][td]何もロック・配置しない（未導入と同じ）[/td][/tr]
[tr][td]AIのピックとレーンを制限[/td][td]AIは収まるチャンピオンだけを選び、選択後はこのModが配置[/td][td]AIがまたトップ2体を選んだり、でたらめに配置したりする[/td][/tr]
[tr][td]自分のピックを制限[/td][td]収まらないカードに鍵をかける[/td][td]自分は何でも選べる（AIは引き続き制限）[/td][/tr]
[tr][td]セーブの試合を参照[/td][td]このセーブで実際に担当したポジションも数える[/td][td]カードの2つのメインポジションのみ（内蔵のLoLチャンピオンは影響なし）[/td][/tr]
[/table]

[b]下のチャンピオンリスト：[/b]バン/ピック画面に登場したすべてのチャンピオン。1ページ24体、◀ ▶ でページ送り。
[list]
[*]各行に5つのポジションボタン（トップ / ジャングル / ミッド / ボット / サポート）。[b]緑 = そのポジションを担当できる[/b]。クリックで切り替え。
[*]チャンピオンの後ろの表示：[b]内蔵[/b] = LoL公式メインポジション；[b]自動[/b] = カードのメインポジション + セーブの戦績；[b]手動[/b] = あなたが変更したもの。[b]↺[/b] で元に戻す。
[/list]

[table]

[tr][td][lock][/td][td]enabled[/td][td]on[/td][td]全体スイッチ[/td][/tr]
[tr][td][/td][td]ai[/td][td]on[/td][td]AIのピックを制限し、AIチームを配置[/td][/tr]

内蔵のLoLチャンピオンを変えたいとき：F7 パネルでクリックするか、[positions] に league_xxx=… を1行書きます（settings.ini が内蔵リストより優先）。

[h2]ほかのModとの併用[/h2]
[list]
[*][b]Patch Meta AI：[/b]併用できます。推奨はロックされたチャンピオンをスキップし、以前に覚えたメインポジションも自動で引き継ぎます。
[*]もう一つのポジションロックMod（Champion Position Lock）とは[b]同時に使わないでください[/b]。ロックが重なり、両方の条件を満たすチャンピオンしか選べなくなります。
[*]チャンピオンModの側で対応は不要です。
[/list]

[h2]問題があるとき[/h2]
Modフォルダの diag.log に、Modが読み取った内容とロックが効いたかどうかが記録されます（起動のたびに書き直し、前回分は diag.prev.log）：
[list]
[*][draft]：AIの各ピックで、空いているポジションとロックしたチャンピオン；
[*][seat]：AIチームの各チャンピオンが担当できるポジションと、このModが割り当てたポジション・選手（熟練度つき）；
[*][athletes]：読み取った選手の熟練度；
[*][check]：各チームのピックが1人1ポジションに収まるか；
[*][result]：大会の各試合で各チャンピオンが実際に担当したポジション。
[/list]
コメントに diag.log を添えていただくと、原因を最も早く特定できます。

[h2]よくある質問[/h2]
[list]
[*][b]F7 パネルのボタンが緑から灰色になった？[/b]灰色は「オフ」です。もう一度クリックすれば緑に戻ります。
[*][b]あるModチャンピオンがいつも変なポジションに置かれる？[/b]上の「ほかのModのチャンピオンをロックするには」を参照し、F7 でポジションをクリックしてください。
[*][b]自分のチームのレーンが変えられた？[/b]いいえ。配置するのはAIチームだけで、自分のチームは入れ替えフェーズで決めます。
[*][b]ピックが止まることは？[/b]ありません。合うチャンピオンがいないときはすべて解除されます。
[/list]

[h2]互換性[/h2]
ネイティブMod（安定版 Mod API）。ゲーム 0.6 以降、AIのレーン配置は 0.6.4 以降が必要です。セーブは変更しません。いつでも購読を解除できます。無料・MITライセンス。
